Srutilekha for macOS (Apple Silicon, macOS 12 or newer)
=======================================================

1. Drag Srutilekha.app onto the Applications folder in this window.

2. First launch. The app is not signed by Apple, so macOS blocks it the first time:
   - Double-click Srutilekha in Applications. macOS says it cannot be opened.
   - Open System Settings > Privacy & Security, scroll down and click
     "Open Anyway" next to Srutilekha, then confirm.
   (On macOS 14 and earlier you can also right-click the app and choose Open.)

3. On first launch Srutilekha:
   - adds Workspace > Scripts > Srutilekha to DaVinci Resolve 21.1 or newer
     (start Resolve once before this so its settings folder exists),
   - starts its menu bar helper and sets it to start at login,
   - asks for your ElevenLabs API key, which is stored in your login Keychain.

4. Restart Resolve, then click Workspace > Scripts > Srutilekha.

Resolve 21.0 and earlier are not supported by the Mac app yet.
Intel Macs are not supported by this build.
